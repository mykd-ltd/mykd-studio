# Soulitude7 local rules

Add this file to your Soulitude7 project in Claude. The Soulitude7 skills read it before every build.

Local rules sit on top of the design system. They never change a locked brand rule: logo, colour, type or the yellow rules. MYKD reviews logged local rules before each release and may move them into the design system.

Write one rule per line, starting with the date and your name. Log each new rule with the s7-system skill so MYKD sees it.
