Before you start

Three things to have in place

  1. A Claude Pro plan or above. Skills need code execution, so check it is switched on in Claude's settings.

  2. Access to the shared files. MYKD shares the design system, the template deck and the social tiles canvas with the email address on your Claude account. Open each link under Shared with you once to check it opens. If one does not, email michael@mykd.co.uk.

  3. A Soulitude7 project in Claude. Create a project called Soulitude7 and add the local rules file to it. Your own rules go in that file, and updates never touch it.

Install

Choose how you use Claude

The desktop app route updates itself. The web route takes a manual swap at each release. Both install the same four skills: s7-deck, s7-brochure, s7-social-tile and s7-system.

Recommended

Claude desktop app

  1. Open Customize in the sidebar, then Plugins.

  2. Select Add marketplace and enter:

    mykd-ltd/mykd-studio

  3. Find Soulitude7 in the list and select Install.

  4. On the MYKD studio marketplace, turn on Sync automatically.

  5. Start a chat in your Soulitude7 project and ask Claude to check the Soulitude7 system. It confirms the release.

Download the plugin (1.1.1)

If the marketplace will not add, download the plugin and use the upload option on the Plugins page instead. Updates are then manual, as on the web.

Any browser

Claude on the web

  1. Download the skills below and unzip the file. It holds four skill files, one per skill.

  2. Go to Customize, then Skills. Select +, Create skill, then Upload a skill.

  3. Upload each of the four files in turn: s7-deck.zip, s7-brochure.zip, s7-social-tile.zip, s7-system.zip. Leave them zipped.

  4. Check all four are switched on.

  5. Start a chat in your Soulitude7 project and ask Claude to check the Soulitude7 system.

Updates

Each release replaces the skills whole

A release overwrites the four skills. It does not merge with local edits, so any edit made to a skill file is lost at the next update. That keeps every copy identical to the release MYKD tested.

Local changes belong in the local rules file in your project, which updates never touch. Before every update, ask Claude to check the Soulitude7 system. If it finds edits, it offers to log them here first.

Update in the desktop app

  1. Ask Claude to check the Soulitude7 system and log anything it finds.

  2. Customize, Plugins, the MYKD studio marketplace, Check for updates.

  3. If Claude warns that local edits will be overwritten, stop and go back to step 1.

Update on the web

  1. Ask Claude to check the Soulitude7 system and log anything it finds.

  2. Customize, Skills: delete the four Soulitude7 skills.

  3. Download the current skills from Install and upload all four again.
